# 🖥️ منظومة مراقب الأصول التقنية (Technical Asset Monitor)
**نظام إدارة ومتابعة الأصول والعهد التقنية — الشركة الليبية للاتصالات الدولية (LITC)**

---

## 🚀 نبذة عن المشروع
منظومة متكاملة وخفيفة مصممة لإدارة وجرد الأصول والأجهزة والملحقات التقنية الموزعة على الإدارات والموظفين، مع متابعة دورة حياة العهدة، وسجل حركات التسليم والاستلام، وتحليلات إحصائية متقدمة، ودعم كامل للغة العربية.

---

## ⚡ التشغيل السريع للمطور (Quick Start)

### 1. المتطلبات
- بيئة [Node.js](https://nodejs.org/) (إصدار 18 أو أحدث).

### 2. التثبيت والتشغيل
```bash
# 1. تثبيت الحزم والمكتبات
npm install

# 2. تشغيل السيرفر
npm start
```

### 3. الدخول للمنظومة
- افتح المتصفح على: `http://localhost:3000`
- **بيانات الدخول الافتراضية:**
  - اسم المستخدم: `admin`
  - كلمة المرور: `admin2026`

---

## 📁 هيكلية المشروع الأساسية
- `server.js`: الخادم الأساسي لنظام Node.js / Express مع قاعدة بيانات SQLite.
- `server_firebase.js`: النسخة السحابية المتوافقة مع Firebase Firestore و Vercel.
- `data/inventory.db`: ملف قاعدة البيانات المحلي (SQLite) شاملاً الجداول والبيانات.
- `public/`:
  - `index.html`: لوحة التحكم والجداول والإحصائيات والمودالات.
  - `login.html`: واجهة تسجيل الدخول العصرية.
  - `org-structure.html`: الهيكلية التنظيمية والشجرة الإدارية.
  - `view.html`: صفحة بطاقة الأصل (للمسح عبر QR).
  - `js/app.js`: المحرك البرمجي الأساسي للواجهة الأمامية.
  - `js/i18n.js`: قاموس اللغات والترجمة.
  - `css/styles_v2.css`: التنسيقات والمظهر الزجاجي.
- `SYSTEM_DOCUMENTATION.md`: **التقرير الفني الشامل** الذي يحتوي شرحاً تفصيلياً لكافة وظائف المنظومة، الجداول، والـ APIs.

---

## 🌟 أبرز المميزات
1. **جرد شامل لكافة الأصول:** أجهزة كمبيوتر (مكتبي / محمول)، طابعات شبكية مع IP، أجهزة بصمة، أكسس بوينت، هواتف Cisco، وشاشات متعددة.
2. **سجل الحركات التاريخي (Audit Trail):** تسجيل آلي لكافة تنقلات العهدة بين الموظفين والأقسام.
3. **هيكلية تنظيمية رباعية المستويات:** مجلس الإدارة -> الإدارات -> الأقسام -> الوحدات.
4. **تحديث لحظي بالـ Server-Sent Events (SSE):** مزامنة فورية للتعديلات بين جميع المستخدمين بدون تحديث الصفحة.
5. **استيراد وتصدير فائق الذكاء مع Excel:** معالجة ذكية للأعمدة ومنع تكرار السجلات.
6. **إدارة صلاحيات دقيقة (RBAC):** تحديد صلاحيات الإضافة، التعديل، الحذف، والتقارير لكل مدخل بيانات.
7. **بطاقة أصل قابلة للطباعة:** طباعة مواصفات الجهاز على ورق رسمي مروّس.
